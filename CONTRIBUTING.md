# Contributing to BattleLayer

Report bugs with the app version, Windows version, display mode, reproduction steps, and a screenshot or recording. Remove personal information from recordings.

For changes, fork the repository, create a feature branch, and open a pull request against main. Explain the user-visible change and how it was tested. Keep generated binaries and node_modules out of commits. Only the maintainer grants write access and merges changes.

Run `npm ci`, JavaScript syntax checks, and `npm start`. Test map navigation, measurements, scene save/open, and the feature changed. Desktop changes should be tested on Windows, including click-through recovery. Never describe mocked checks as native desktop verification.

The project currently reserves its copyright; public source visibility does not grant an open-source licence. Discuss permission before distributing modified versions. Contributions must be yours to submit and must not include unlicensed map artwork.
