# BattleLayer 0.2.0 — Windows preview

Download **BattleLayer-0.2.0-portable.exe** from Assets, save it, and run it. No Node.js installation is needed. SHA256SUMS.txt contains the executable's checksum.

## Included
- Transparent always-on-top overlay above Photos or another desktop app.
- Ctrl+Shift+Space to toggle drawing/click-through, tray recovery and display selection.
- Action Wheel, animated spells, templates, dice and measurements.
- Freehand/corner-based water, lava and fog regions; rain, snow and wind.
- Imported-map fit, pan, zoom, rotation and grid calibration.
- Scene JSON save/open and undo.

## Start
Open and arrange your map in Photos, launch BattleLayer, select the monitor, and align the grid. Right-click to open the Action Wheel. Ctrl+Shift+Escape quits.

## Preview limitations
The executable is unsigned. This is an early preview, not a fully tested stable release. Photos movement is independent of overlay effects. There is no autosave, projector perspective correction or remote synchronization. Scene effects are procedural overlays.

Map artwork in documentation examples is not included as a reusable asset. See the repository README for the visual guide and usage rights.
